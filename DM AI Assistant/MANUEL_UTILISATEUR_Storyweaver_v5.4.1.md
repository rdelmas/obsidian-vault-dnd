# Annexe — Side Quests & Interludes (v5.4.1)
**But** : Insérer des **Respirations** entre scènes canons sans changer le SPINE.

## Règles d’usage
- Interludes = **pas** des scènes canons ; 0–3 Side Quests ; **optionnels**.
- Respect des références :
  - Matrix A1 : anomalies **seulement** en terrain/exploration.
  - Clair‑Obscur B1/B3 : fragments/angles morts ; vérité partielle.
  - Frieren C1/G2 : respiration/voyage ; **ruines omniprésentes**.

## Matrice d’accroches Side Quests
- **Sources** : S1 PNJ ; S2 Anomalie ; S3 Vestige ; S4 Événement.
- **Liens** : L1 Fragment ; L2 Trace empire ; L3 Politique ; L4 Écho Trame.
- **Qualité** : ≥1 Orientation MJ ; ≥1 vecteur (objet ou témoin) ; jamais un indice critique unique.

## Workflow (Pathfinder)
1) `MODE: REFERENCE FILTER` (R‑0001..R‑0003) → activer dials.
2) `MODE: DRAMATURGIE — PATHFINDER` → générer 2–4 hooks (S×L).
3) Jouer 0–3 Side Quests → noter seulement les **effets stabilisés** dans l’Index Global (VALIDÉ).

## Implémentation SPINE
- Ajouter la section **Interludes (Respirations — Frieren C1)** à l’ARC‑01.
- Ajouter **Ambiance & Règles d’influence** pour clarifier Matrix/Clair‑Obscur/Frieren.
