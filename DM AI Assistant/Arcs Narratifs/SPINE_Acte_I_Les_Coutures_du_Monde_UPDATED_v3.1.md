# Acte I — Les Coutures du Monde (UPDATED v3.1)

> **Directive MJ** : Cet acte NE révèle **rien** de la Trame ni des nœuds. Le moteur narratif est **politique** : un **complot** pour **destituer la Protectrice de Valdorian**.

---
## 0) Glossaire des PLACEHOLDERS (à remplacer plus tard)
- **[VILLAGE_CIBLE]** : village touché en Scène 2.  
- **[SITE_CEREMONIE]** : lieu public de la cérémonie d'Edelmark (pont / place d'honneur / poste-frontière).  
- **[PRETEXTE_CEREMONIE]** : raison officielle d'Edelmark (inauguration / remise d'honneurs / signature d'accord).  
- **[BARON_A]**, **[BARON_B]** : deux nobles de Valdorian poussant la destitution.  
- **[MARTEAU_LARME]** : capitaine régional (Larme de Fer) impliqué dans l'opération.  
- **[FORME_AUDIENCE]** : format du dénouement (Beaulys / Légat itinérant / Couronne).  
- **[RELAI_ENTREPOT_NOM]** : nom d'entrepôt/ponton relais de la Larme.  
- **[TEMOIN_BATELIER_NOM]**, **[CAPITAINE_PATROUILLE_NOM]**, **[CLERC_SUBALTERNE_NOM]** : témoins potentiels avec une courte ligne.

## 2) Plotline ÉPIQUE — Destitution d’Ysandre (Variante A : Débordement différé)
**Principe** : la Larme **n’explique ni ne contrôle** le phénomène, mais **exploite** ce qu’un accident passé a produit (créatures / humains brisés / bêtes folles), **capture** et **relâche** ces retombées **au bon moment** pour créer un **événement public** imputable à Valdorian. Edelmark **accuse** aussitôt de « **nouvelle arme** ». Osmard **sabote** la réponse d’Ysandre et **pousse** un **courant de destitution** où son nom émerge comme **intérim technique**.

## 4) Scènes clés (Arc I — Destitution)
> **Usage** : chaque scène est un **module**. Tu peux changer les lieux/PNJ, mais **garde** : *Cadre → Preuves épiques → Orientations* et *Sorties*.

### SCÈNE 1 — Parade & Audience de Beaulys (installer la Guerre Froide)
- **Cadre** : Halle / Quais de Beaulys. Arrivée d’un émissaire d’Edelmark ; marchands furieux.  
- **Objectifs MJ** : Donner le **feeling** de tension ; placer Ysandre **ferme** mais **sous pression**.  
- **Déclencheurs** : plaintes de péages, escorte lourde, protocole cassant.  
- **Preuves épiques** : discours martiaux, regards glacés ; promesse d’Ysandre de **renforcer** les routes.  
- **Orientations** : le prévôt des quais **invite** les PJ à inspecter **[VILLAGE_CIBLE]** **ou** un **convoi "pas net"** (ouvre SCÈNE 2).  
- **Complications** : duel rhétorique ; prise à partie par une guilde.  
- **Sorties** : incident majeur imminent ; **tout est politique**.

### SCÈNE 2 — Désastre spectaculaire (horde aberrante / village fantôme)
- **Cadre** : environs de **[VILLAGE_CIBLE]**.  
- **Objectifs MJ** : Poser un **danger incontestable** non humain **sans** expliquer le phénomène.  
- **Déclencheurs** : cloches, traces de lutte, animaux terrorisés.  
- **Preuves épiques** : **cages bâchées** vides (barres tordues), chariots grillagés abandonnés, batelier **[TEMOIN_BATELIER_NOM]** paniqué.  
- **Orientations** : **[TEMOIN_BATELIER_NOM]** désigne **[RELAI_ENTREPOT_NOM]** (piste **Larme**) ; rumeurs d’une **[PRETEXTE_CEREMONIE]** sur **[SITE_CEREMONIE]** (piste **cérémonie**).  
- **Complications** : milice nerveuse ; bêtes résiduelles.  
- **Sorties** : 2 routes claires : **relais de la Larme** (SCÈNE 4 en amont) **ou** **cérémonie** (SCÈNE 4 le jour J).

### SCÈNE 3 — Secours sabordé (promesse d’Ysandre → contre‑ordre)
- **Cadre** : cour de chancellerie / route de patrouille.  
- **Objectifs MJ** : rendre **visible** le sabotage **interne**.  
- **Déclencheurs** : ordre public d’Ysandre ; **[CAPITAINE_PATROUILLE_NOM]** prêt à partir.  
- **Preuves épiques** : capitaine renvoyé “par prudence”, bornes où l’on **fait tourner** la troupe ; sous‑officiers répètent la même formule.  
- **Orientations** : **[CAPITAINE_PATROUILLE_NOM]** invite les PJ à **voir** la **[PRETEXTE_CEREMONIE]** sur **[SITE_CEREMONIE]** ; ou demande d’enquêter sur **[RELAI_ENTREPOT_NOM]** (SCÈNE 4 préparatoire).  
- **Complications** : un **[BARON_A]** veut “prendre la main” ; embuscade d’hommes de main.  
- **Sorties** : PJ **suspectent** un **saboteur interne** (sans nommer Osmard).

### SCÈNE 4 — Cérémonie‑piège d’Edelmark (débordement différé)
- **Cadre** : **[SITE_CEREMONIE]** ; bannières, tribunes.  
- **Objectifs MJ** : grand spectacle + **accusation publique**.  
- **Déclencheurs** : étendards levés, serments, cloches.  
- **Action** : **lâcher** des **créatures / humains brisés** capturés lors de J‑10/J‑7 → carnage localisé.  
- **Preuves épiques** : bâches déchirées, loquets, attelages suspects ; nervis en fuite avec **goutte de fer** (Larme).  
- **Orientations** : poursuite **des nervis** vers **[RELAI_ENTREPOT_NOM]** **ou** requête d’**audience** pour contester l’accusation (SCÈNE 6).  
- **Complications** : émeute ; chevaliers edelmarkers visent les PJ ; foule réclame des têtes.  
- **Sorties** : accusation publique “Valdorian = **nouvelle arme**” virale.

### SCÈNE 5 — Courant de destitution (Osmard, “solution neutre”)
- **Cadre** : salon de **[BARON_A]** ou **[BARON_B]** ; marché ; tribune improvisée.  
- **Objectifs MJ** : montrer **le bénéficiaire politique**.  
- **Déclencheurs** : motion symbolique ; cris “Ysandre nous laisse périr !”.  
- **Preuves épiques** : réunions “spontanées” très cadrées, mêmes éléments de langage (“stabilité”, “prudence”) ; cartes “de sécurité” qui envoient **toujours** ailleurs.  
- **Orientations** : un intendant **cite** le **Sous‑Chancelier adjoint** comme “l’homme qui **comprend** la machine” → ouvre **SCÈNE 6** ; un marchand révèle un **calendrier** de caravanes et de “rassemblements” coïncidant avec les coups de **[MARTEAU_LARME]** → retour **SCÈNE 4 bis** (relai).  
- **Complications** : duel d’arguments ; pression pour rallier l’intérim **Osmard**.  
- **Sorties** : **Osmard** devient le **nom plausible** d’un intérim “technique”.

### SCÈNE 6 — Audience finale (**[FORME_AUDIENCE]**) : Deux voies de victoire
- **Cadre** : salle d’audience (**[FORME_AUDIENCE]**).  
- **Objectifs MJ** : offrir aux PJ le **choix** du dénouement politique.  
- **VOIE A — Démanteler la Larme (bras armé)** : présenter **cages**, **attelages**, **nervis capturés**, **[RELAI_ENTREPOT_NOM]** → la Larme a **déplacé** des retombées d’un incident **antérieur**.  
- **VOIE B — Exposer la chaîne (preuve politique)** : **témoins** (**[TEMOIN_BATELIER_NOM]**, **[CAPITAINE_PATROUILLE_NOM]**, **[CLERC_SUBALTERNE_NOM]**), **objets** (goutte de fer, bâches), **calendriers** (convocations, cérémonies) → **Edelmark** avait **prétexte** (**[PRETEXTE_CEREMONIE]**) et **intérêt**, **Osmard** a **saboté** la défense ; la Larme a **orchestré** l’attaque.  
- **Orientations** : si une pièce manque, **légat** propose d’entendre **un seul témoin** supplémentaire pour combler le trou.  
- **Complications** : rhétorique agressive d’un émissaire d’Edelmark ; barons menacent de rompre avec Ysandre.  
- **Sorties** : 
  - **A** : incidents taris → destitution échoue.  
  - **B** : saisine royale → **Osmard** et complices pris en charge ; Edelmark désavoué publiquement.
