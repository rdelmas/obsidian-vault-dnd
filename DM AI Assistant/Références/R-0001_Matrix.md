# PROFIL
Œuvre‑source mobilisée **uniquement** pour : le doute méthodique sur la nature du réel, les **systèmes de contrôle** (ici **faillibles**), et la **question du choix** vs destin — sans import d’esthétique cyberpunk, d’IA, ni de mythologie de « l’Élu ». On transpose en **symboles et effets perceptifs locaux** (reflets, anomalies magiques circonscrites), jamais en simulacre numérique global.

# INCLUDED — ce que l’on autorise (et dose)
- Doutes **situés** sur le réel (A1=5) : phénomènes perceptifs **locaux**, indices contradictoires, révélations fragmentaires.
- Contrôle **faillible** (A2=2) : pressions institutionnelles qui **craquent** (décret mal recopié, officier hésitant, protocole troué).
- Libre arbitre ciblé (A3=3) : dilemmes et choix significatifs **pour Fenrix** (et éventuellement quelques PNJ explicitement désignés).
- Oracle **soft** (B2=2) : information **partielle/ambiguë** qui ouvre **2 pistes concrètes** (objet + témoin).
- Trahison **périphérique** (B3=1) : opportunisme d’un PNJ **secondaire** ; **jamais** au sein du groupe de PJ.
- Double identité **limitée** (B4=1) : **PNJ Fenrix** uniquement ; indices discrets (aucune double vie « à la Neo »).
- Reflets (E2=1) : symboles **légers** (métal poli, eau sombre, seuils), sans invalider les indices matériels.
- Anomalies magiques (E3=2) : distorsions **circonscrites** (un seuil, une zone, un artefact) ; **réparables** ou **exploitables**.
- Questionnement du réel (F1=4) et **choix** (F2=2) : privilégier des **questions** plutôt que des affirmations métaphysiques.

# EXCLUDED — interdits (coupe‑circuits)
- Esthétique **cyberpunk** : code vert, interfaces numériques, cuir/lunettes, armes automatiques.
- **Technologie/IA/robots**, « agents logiciels », **monde simulacre numérique**.
- **Structure initiatique** (appel→élu→résurrection), **mentor** type Morpheus, **prophétie de l’Élu**, **fracture centrale** (« tu n’es pas l’élu »), **résurrection symbolique**.
- **Antagoniste impersonnel**/systémique (type Agent Smith), **archétype du héros sceptique**.
- **Aliénation de masse** ou identité métaphysique « trame du soi ».

# VECTEURS (éléments concrets conseillés — univers non‑tech)
- **Objets** : miroir d’obsidienne / eau noire ; prisme gravé ; sceau/jeton de véridiction ; masque de cérémonie (reflet/visage).
- **Témoins** : devineresse à l’agenda opaque ; scribe du protocole ; messager « trop sûr » ; notable « raisonnable » qui **minimise** une anomalie.
- **Effets** : écho auditif sans source ; micro‑ralenti **subjectif** ; ondulation d’air au seuil ; **empreinte magnétique → flux magique** local.
- **Symboles** : **seuils** (portes, arches), **reflets**, **murmures codifiés** (non numériques), **marques** répétées (tesselles, runes) → indice d’**ordonnancement humain** (artificiel, non illusoire).

# UTILISATIONS (Pathfinder / Dramaturgie)
- **Pathfinder — Beats/Scènes**
  - (A1=5) Au plus **1 effet perceptif local** par scène (jamais de faux monde).
  - (F1=4) Préférer **indices contradictoires** → *fail‑forward* vers **révélation partielle** (B2).
  - (A2=2) Mettre en scène **micro‑failles** du contrôle (un porte‑sceau vacille, copie d’acte fautive).
  - (B3=1) Si tension requise : **déplacer la trahison** sur un **PNJ périphérique** (jamais intra‑groupe PJ).
  - (E3=2) Anomalie **magique** locale et **résoluble**.
- **Dramaturgie — garde‑fous**
  - **Interdits** : mentor, élu, résurrection, agent impersonnel, arc initiatique, simulacre global.
  - **Autorisé** : Oracle *soft* (B2) = **vérité partielle** + 2 **pistes concrètes** (objet + témoin).
- **Scène canon — Quality Gates**
  - Pour chaque **lien critique**, garantir **≥2 vecteurs** (**objet** + **témoin**).
  - Toujours ≥1 **Orientation MJ** (issue en avant) ; les effets perceptifs n’**annulent pas** les indices matériels.
