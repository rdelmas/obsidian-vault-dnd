# Résumé MJ — Le Complot
**Trois étages convergent :**
1. **Larme de Fer** → provoque des anomalie via des manipulation sur le noeud.
2. **Bellicistes d’Edelmark** → exploitent incidents pour pousser à l’escalade.
3. **Osmard Delvore (L‑0012)** → filtre rapports, réoriente PJ, affaiblit Ysandre.

**Lien tri-latéral :**
- Delvore croit servir la stabilité ; il reçoit des informations d’un **Marteau** de la Larme.  
- Ce Marteau est discrètement **soutenu** par les bellicistes d’Edelmark.  
- Eisenwald n’apparaît jamais, mais **oriente l’échiquier**.  

> **Eisenwald → Larme → Delvore** : triangle de manipulation sans contact direct.

**Climax** : les PJ coupent le nœud pensant neutraliser une arme.
